# llm-code-wiki distribution manifest
# Each line is: PATH [POLICY]
#   PATH    — repo-relative path to fetch into the target project
#   POLICY  — optional update policy used by /wiki-update; defaults to `overwrite`
#             - overwrite: fetch + replace unconditionally
#             - keep:      skip if local exists; notify when upstream differs
# Lines starting with `#` and blank lines are ignored.
#
# Hook scripts (.sh) require `chmod +x` after fetch — see INSTALL.md "Remote install".
# `wiki/` seed files use the `keep` policy so /wiki-update never overwrites user customizations.
#
# `.claude/settings.json` is intentionally NOT in this manifest. The remote-install
# flow delegates settings.json merge to .claude/skills/wiki-install/SKILL.md (Step 5/5b),
# and /wiki-update applies the same merge protocol — both preserve unrelated permissions/env entries.
# `CLAUDE.md` is similarly not in this manifest; its `## Auto-maintained wiki` section is
# managed by /wiki-install Step 6 and refreshed by /wiki-update.
