# llm-code-wiki distribution manifest
# Each line is a repo-relative path that must be fetched into the target project
# during a remote install. Lines starting with `#` and blank lines are ignored.
#
# Hook scripts (.sh) require `chmod +x` after fetch — see INSTALL.md "Remote install".
# `wiki/` seed files are templates the user customizes; the remote-install fetcher
# must skip-if-exists for those paths to preserve user content.
#
# `.claude/settings.json` is intentionally NOT in this manifest. The remote-install
# flow delegates settings.json merge to .claude/skills/wiki-install/SKILL.md (Step 5/5b),
# which knows how to merge into an existing settings.json without clobbering unrelated
# permissions/env entries.
